## 2025-01-22 - Session 1: Fundaciones

### Service Worker Idle Issue Fix
- **Problema**: Despues de ~30s de inactividad, el boton "Open" mostraba error de comunicacion con la extension.
- **Causa raiz**: Chrome Service Workers se ponen idle automaticamente despues de ~30s.
- **Solucion**: Retry con exponential backoff en `sendMessageWithRetry()` (3 intentos: 500ms -> 750ms -> 1125ms).
- **Archivos**: `content/content.js`
